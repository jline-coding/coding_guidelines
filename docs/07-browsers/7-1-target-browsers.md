# 7-1. 対象ブラウザ環境（PC / SP）

## 以下のブラウザ環境で正しくレイアウト、動作する様に作成する

### PC

**Windows（OS / Windows 10.xおよびWindows 11.x）**
- Microsoft Edge・Google Chrome・Firefoxの各最新版

**Mac OS(12以降)**
- Safari・Google Chrome・Firefoxの各最新版

### SP

**iPhone**
- iOS 16以降のSafari最新版

**Android**
- Ver-11以降のスマートフォン搭載のブラウザー最新版(主にChrome)
